# Exemplos de Machine Learning utilizando a classe Pipelines

Este repositório contém exemplos simples e práticos para o aprendizado de conceitos de Inteligência Artificial, cobrindo o uso de pipelines.

## 🚀 Conteúdo do Repositório

O projeto aborda os seguintes tópicos de forma progressiva:
* **Módulo Pipeline:** Exemplos práticos usando fluxos automatizados.

## 🛠️ Pré-requisitos

Antes de executar os exemplos, certifique-se de ter o Python instalado. Recomenda-se o uso de um ambiente virtual.
